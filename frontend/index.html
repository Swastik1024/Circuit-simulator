🎓 Object-Oriented Programming (OOP) Architecture Breakdown (For Viva / Project Review)

      

        

          
1. Abstraction & Interfaces

          
Evaluatable interface and abstract classes CircuitNode & LogicGate define a uniform contract (evaluate(), toBooleanExpression()) without exposing gate-specific logic to the board.

        

        

          
2. Inheritance Hierarchy

          
InputSource, LedBulb, and LogicGate inherit coordinates, pin counts, and wire lists from CircuitNode. All 7 gates extend LogicGate.

        

        

          
3. Runtime Polymorphism

          
When CircuitBoard.simulate() iterates over CircuitNode objects, Java dynamically dispatches computeGateLogic() to AndGate, XorGate, etc.

        

        

          
4. Encapsulation

          
All component fields (activeHigh, incomingWires, glowing) are private with validated getters/setters that keep voltage (0.0V / 5.0V) synchronized.

        

        

          
5. Template Method & Factory

          
LogicGate.evaluate() handles cycle detection and unconnected pin validation before calling the abstract hook computeGateLogic(). GateFactory instantiates gates.

        

        

          
6. Custom Exception Handling

          
CircuitValidationException and DFS cycle detection protect the simulation engine against short-circuits (feedback loops) and floating input pins.
